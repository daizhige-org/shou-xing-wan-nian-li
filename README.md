# 寿星万年历 国际版

一个可直接用浏览器打开的天文历法工具：公历 / 农历 / 干支互查、日月坐标、日月食、行星与恒星星历、日月升降、气朔推算。

本项目基于 **叶风羲（风羲）的「寿星天文历 风羲版 V5.09.04」** 单文件网页版。
天文与历法算法沿用原版，本项目做的是**工程化拆分、时间基准修正和面向非中国大陆用户的界面改造**。

### 与 sxwnl/sxwnl 5.10 的关系

两者是**同源分支，不是上下游**。许剑伟原版《寿星天文历》发展到 V5.09 之后分成两条线：

- **5.10 线** —— 许剑伟继续维护，即 [sxwnl/sxwnl](https://github.com/sxwnl/sxwnl)（当前 V5.10.3）。
- **风羲版 5.09.04 线** —— 叶风羲自 V5.09 起独立修改的单文件网页版，本项目在此之上继续开发。

两条线自 V5.09 之后各改各的，互不包含。5.10 的改动（例如 ΔT 数据优化）本项目并未合入，
反过来风羲版的改动 5.10 也没有。需要参考对方时按提交逐条移植，不能整体跟进。

## 相对上游的改动

### 1. 工程结构

上游只发布一个几万行的 `.htm` 单文件。本项目把它拆成
`index.html` / `styles.css` / `calendar-core.js` / `calendar-app.js`，
使样式与页面逻辑可独立修改，核心算法保持在 `calendar-core.js` 中便于跟进上游。

### 2. 时间基准修正（正确性问题）

原版「UTC/TD」复选框的换算里混入了**浏览器本地时区** `curTZ`：

```js
jd -= curTZ/24 + dt_T(jd);  td = ' UTC'
```

算出来其实是本机当地时间，却标成 UTC。原作者在中国大陆，`curTZ = -8` 恰好把 TD 变成北京时间，
所以这个错误一直没暴露。日食表、月食表、地方日食表、天象表的 UT 列都有同样的问题。

现在改为：

- 复选框改成**「当地时区 / UTC / TD」三选一**，标签与实际含义一致；地方日食表原来连选项都没有，也补上并在表头注明时间基准。
- 新增 `zoneOfs()` / `zoneStr()` / `TD2scr()` / `scr2TD()` 一组换算函数，取代散落各处的 `curTZ/24 ± dt_T(jd)`。
- 「当地时区」取页面顶部**地点选择框**所选地点的 IANA 时区，不再跟浏览器走。
- 时差向浏览器内置的 **IANA 时区库（`Intl`）** 查询，夏令时与历史时制变更（美国二战战时制、中国 1986–91 年夏令时等）均按该库为准，随浏览器更新，无须本程序维护。1900 年以前时区尚未成立，一律改用该时区的标准时差。
- 「此刻」按钮与各页默认日期改按所选地点的当地时区取「今天」；八字页的输入时刻同样按该时区解释。
  原版这里跟的是电脑时区（作者假定用户在中国），而经度已经跟着地点框走，两者不一致会让日柱、时辰整体错位。
  八字的年柱按立春、月柱按节气，本就与时区无关；日柱与时辰由该地经度换算的真太阳时界定。
- 升降页（日月升降、年度升降表、太阳时差表）的输出由原版硬编码的北京时间改为所选地点的区时，
  与月历页左栏的升降数据统一。这三处坐标本就取自地点框，时刻却仍按北京时间输出，同一个量在两页有两种基准。

（农历与节气的时刻**仍是北京时间**，这是农历的定义所在——月首与节气归属以东经 120° 区时为准，
不随地点变动。气朔页已就此加注说明。）

### 3. 地点与时区国际化

- 地点选择器由原版的国内城市表改为**全球机场数据**（IATA 代码 / 城市 / 国家 / 经纬度），按国家分组。
- 经纬度经 `tz-lookup.js` 解析为 IANA 时区名，右上角显示该地「地方时间」。
- 顶部另设「外地时间」辅助时钟，可按洲 / 时区独立选择，与主地点互不影响。
- 主地点默认 SEA，可由 URL 的 `?airport=` 指定；外地时间时钟默认 Asia/Shanghai，选择结果存入 localStorage。

### 4. 界面

- 重做视觉样式与主要布局，统一表格、输入框、工具栏与帮助区的宽度表现；日月食页面的地图与表格对齐、等宽字体等问题一并处理。两档响应式断点，兼顾窄屏。
- 月历格子可点击，日期详情固定显示在左侧信息栏，默认显示今天。
- 月历只保留农历信息并加入每日干支，隐藏「儿童节」等现代节日。
- 日月坐标表（表一地心 / 表二站心）由旧式 `<table>` 改为语义化分区排版。
- 「日食概略」从当前查询状态初始化，不再固定回到 2008 年；日期与查询输入框支持回车提交。

### 5. 繁简转换

顶部「繁 / 简」按钮基于 OpenCC 做全页转换，包含 `title` / `placeholder` 等属性文本，
并用 MutationObserver 跟随动态生成的表格内容。当前模式保存在 URL 与 localStorage 中。
针对历法用字（如「曆」）维护了一份小的覆盖词表，仅收录默认词典处理不当的条目。
繁体模式下切换到 zh-Hant 字体栈。

### 6. 纪年显示

- 支持负数年份输入并转为 BCE（`B212`、`*212`、`-211` 三种写法），统一 BCE 文案。
- 1949 年后并列显示中华民国纪年。
- 并列显示近代日本年号（明治 / 大正 / 昭和 / 平成 / 令和）。

### 7. URL 状态持久化

当前页面、年月日、时刻、天体、地点、繁简模式都写进 URL 查询串，
刷新与分享链接都能回到同一视图。

### 8. 帮助

帮助内容改为全屏模态框（不透明背景、右上角关闭、点击外部与 Esc 关闭），
并把原版说明书（`help/readme.htm`、`sm1`–`sm9` 及插图）一并收入仓库，从模态框中链接过去。

## 历表校勘

`docs/ddbc_shouxing_diff.md` 记录了本历生成的朔望月表与
**DDBC 时间权威数据库**（[Dharma Drum 佛學規範資料庫 · authority_time](http://authority.dila.edu.tw/time/)）
历史月表的逐月比对结果：朔日命中 9,490 / 10,025，差异多为 ±1 日，另有月长、月名 / 闰月、改元切分月等分类统计与样本。

这是把 DDBC 年号与月表接入界面之前的评估材料，尚未接入。
比对所用的 `authority_time` 数据库为第三方数据，未纳入本版本库。
